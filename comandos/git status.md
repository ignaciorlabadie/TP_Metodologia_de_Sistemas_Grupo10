# git status

## ¿Qué hacen? 

- muestra el estado del repositorio
- nos dice en que rama nos encontramos
- muestra archivos agregados, eliminados o modificados

---

## ¿Para qué se usa?

- para ver que archivos fueron modificados, eliminados o agregados 
- ver si hay cambios pendientes sin commit

---
